# Increase Original Super Store

Static website for Increase Original Super Store, with storefront pages for the Apapa and Badagry branches in Lagos, Nigeria.

## Deploy

Publish directory: `dist`. No build command is required.

## SEO files

- `dist/index.html` — Apapa storefront and primary business page
- `dist/badagry.html` — Badagry local landing page
- `dist/products.html` — crawlable phones, gadgets and accessories guide
- `dist/about.html` — business identity and Micheal Aderinto contact page
- `dist/contact.html` — branch contact details and directions
- `dist/faq.html` — searchable customer questions
- `dist/sitemap.xml` and `dist/robots.txt` — crawl and discovery controls

Prices and availability are confirmed through WhatsApp because stock changes quickly. Add the final production domain, official email, social profile URLs, and Google Analytics/Search Console IDs when they are available.
